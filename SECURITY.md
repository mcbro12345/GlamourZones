# Security Policy

## Supported Versions

Only the latest released version of Glamour Zones receives security fixes. Update to the newest release before reporting an issue, in case it is already fixed.

## Reporting a Vulnerability

Report security vulnerabilities privately using GitHub's [private vulnerability reporting](https://github.com/mcbro12345/GlamourZones/security/advisories/new), not a public issue. This keeps details out of view until a fix is available.

Include:

- The affected Glamour Zones version and Dalamud/API version
- Steps to reproduce
- The potential impact

Expect an initial response within a few days. Confirmed vulnerabilities will be fixed and disclosed once a patched release is available.

## Scope

Glamour Zones is a client-side Dalamud plugin that runs inside your own FINAL FANTASY XIV process. It makes no network requests and accepts no connections. It equips your gear sets, runs the extra commands you enter in your rules, and stores your rules locally. Relevant reports include things like unsafe memory access, crashes, or imported rules running commands the user didn't expect.
